Dashboard — open/in-progress/overdue/completed counts, a "Team Pulse"
workload bar per person, and a due-soon list.
Tasks — filterable list, tap to edit, tap the checkbox to mark done,
tap the share icon to send a single task to whoever's assigned.
Team — add members with a name, role, and color; tap the ✕ on a member's
card to remove them (their tasks become "Unassigned," not deleted).
Share — the share icon (top-right) sends a full team status summary
through Android's native share sheet (WhatsApp, email, SMS, Slack, etc).
Every task also has its own "Share with assignee" option.
Export to Sheets — the download icon (top-right) exports all tasks as a
.csv file. Open Google Sheets → File → Import → Upload, and pick the file
— it drops straight into a spreadsheet with columns for Title, Assignee,
Role, Status, Priority, Due Date, Notes, and Last Updated. On Android, if
you save it to Google Drive, tapping it there offers "Open with Google Sheets"
directly.
All data is stored locally on the device (localStorage) — private to that phone.
